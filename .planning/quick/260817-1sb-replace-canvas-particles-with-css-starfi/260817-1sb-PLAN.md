# Quick Task 260817-1sb: CSS starfield replaces canvas particles

Owner asked for a glow halo around the hero dots and for the largest ones to be
4-point stars, matching the sizes, speed and opacity of meganyap.me.

Neither is possible on the existing dots: they are painted on a `<canvas>` by
particles.js, which supports no `box-shadow` and no custom shape. Owner approved
replacing `ParticlesBg` with a DOM starfield, accepting the loss of hover-grab
and click-push.

## Reference values (measured live from meganyap.me, not estimated)

| | value |
|---|---|
| dots | 116 — 51×1px, 42×1.5px, 15×2px, 8×2.5px |
| glow | `box-shadow 0 0 3px rgba(255,255,255,.7)`, `0 0 4px .8` at 2px+ |
| base opacity | randomised per dot, 0.25–0.90 (median 0.47) |
| twinkle | `9s` loop, opacity 0.7↔1, random delay |
| drift | three 2160px layers, rotate ±360° over 360s / 260s / 190s, linear |
| split | 70 / 30 / 16 dots per layer |

## Decisions taken with the owner

- Replace `ParticlesBg` rather than layering a second dot system
- Dot color: `--color-accent` in light, `#fff` in dark (white would vanish on
  the near-white light hero)
- The 8 largest dots render as sparkles at **8px**, not the reference 2.5px —
  a curved 4-point star is not legible at 2.5px. All other sizes are exact.

## Tasks

### T1 — Add `--color-star` token

- **files:** `src/styles/global.css`
- **action:** New token in all four theme blocks (`:root`, `@media dark`,
  `:root.dark`, `:root.light`): `#553ee5` light, `#ffffff` dark
- **done:** Token resolves correctly under both themes and the manual toggle

### T2 — Create `src/components/Starfield.astro`

- **files:** `src/components/Starfield.astro` (new)
- **action:** Build-time generation with a seeded PRNG so the field is stable
  across builds. Three rotating layers; each dot carries base opacity, its
  `::after` carries glow plus the twinkle loop so the two opacities multiply.
  Sparkles use a `mask-image` SVG and `drop-shadow` (box-shadow would halo the
  square border box), and counter-rotate against their layer so they stay
  upright instead of reading as an X at 45°.
- **done:** 116 dots, histogram and layer periods match the table above

### T3 — Swap in the hero

- **files:** `src/pages/index.astro`
- **action:** Replace the `ParticlesBg` import and element with `Starfield`.
  Leave `ParticlesBg.astro` and `public/js/particles.min.js` in the repo,
  unreferenced — reverting is a one-line change.
- **done:** `npm run build` clean, `particles.min.js` absent from `dist/index.html`
