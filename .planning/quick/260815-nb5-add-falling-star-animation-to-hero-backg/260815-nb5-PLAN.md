# Quick Task 260815-nb5: Falling-star animation in hero

Reference: meganyap.me — intermittent shooting star, small head with a fading
trail, travelling diagonally down-left. Not a continuous effect.

Design approved by user in chat before planning. Decision taken: **layer over
the existing `ParticlesBg`**, leaving the purple particle field untouched.

## Constraints

- Zero JS (project JS budget is near-zero; `ParticlesBg` already ships a
  vendored `particles.min.js` and a canvas — a second canvas is not justified)
- Colors from `@theme` tokens only (`--color-accent`), never literal hex
- Must honor `prefers-reduced-motion: reduce`
- No changes to `ParticlesBg.astro`

## Tasks

### T1 — Create `src/components/ShootingStars.astro`

- **files:** `src/components/ShootingStars.astro` (new)
- **action:** Absolutely-positioned, `pointer-events: none` layer holding 5
  `<span class="star">` elements. Each span is the trail (gradient fading to
  `--color-accent`); its `::after` is the head dot with a soft glow. A single
  `@keyframes shoot` translates the star down-left along its rotated local
  axis. Per-star variation via inline custom properties only — `--top`,
  `--left`, `--travel`, `--len`, `--duration`, `--delay`. Intermittency comes
  from the keyframe shape: the streak completes inside the first ~8% of the
  cycle and stays invisible for the rest, so no timer or scheduler is needed.
- **verify:** Component renders 5 stars; streaks appear at irregular intervals;
  color follows the theme toggle with no JS
- **done:** File exists, `astro check` clean

### T2 — Mount in the hero

- **files:** `src/pages/index.astro`
- **action:** Add `<ShootingStars />` immediately after `<ParticlesBg />` inside
  the hero `<section>`, plus its import. Hero section is already
  `relative overflow-hidden` with `z-10` content, so no z-index changes.
- **verify:** Stars visible behind hero copy, above particles, both themes
- **done:** `npm run typecheck` clean, prettier clean, visual check passes

## must_haves

- **truths:** hero shows intermittent shooting stars; no new JS shipped;
  reduced-motion users see none
- **artifacts:** `src/components/ShootingStars.astro`
- **key_links:** `src/pages/index.astro`, `src/styles/global.css`
  (`--color-accent`)

## Out of scope

- Changing or removing `ParticlesBg`
- Scroll- or pointer-driven interactivity
- Any change to the hero headline
